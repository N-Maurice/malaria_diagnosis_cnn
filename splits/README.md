# Shared split manifests

Generate `train_files.csv`, `val_files.csv`, and `test_files.csv` once using
`python -m scripts.create_splits` from the project root after verifying the layout.
The command does not download data. It refuses existing files by default.

Use 70% train / 15% validation / 15% test, stratified by label, with seed 42.
Rounding may alter exact counts. CSV columns are `filepath` and `label`; paths
are POSIX-style relative to the project root, including `data/cell_images/...`.
The splitter sorts paths first and rejects duplicate paths. It does not detect
identical content under different filenames or enforce patient-level separation.
Verify those issues before approving the split; see dataset notes.

Commit the approved small CSV manifests so every member reuses identical splits.
Do not regenerate per experiment or member. Record the manifest Git commit.
Load with `pandas.read_csv`; pass to `build_tf_dataset` with its default path root.
The test set stays untouched throughout training, threshold tuning and
hyperparameter selection. Use validation for experiment comparisons and evaluate
the final selected model on test only after all decisions are frozen.
No real-data manifests have been generated by this scaffold.
